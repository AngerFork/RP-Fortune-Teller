Welcome to RP Fortune Teller! This addon will allow you to tell fortunes within the emote channel to anyone you wish, or just to anyone that will listen. You can also give people their lucky numbers if you are so inclined.

For prophecies, your character will first do whatever action they need to in order to see the future. After a few seconds the button turns into "Reveal" - click it (or run the command again) to reveal what they have seen.

For tasks, your character plays quest-giver: they look for an errand, then hand out a task. Some tasks are general, and some depend on the zone you are standing in. Add your own in tasklists.lua.

There is also a small movable bar with "Prophecy" and "Task" buttons. It starts hidden; turn it on in the options menu or with /rpf_bar, then drag it wherever you like.

Slash Commands for this addon:
	/rpf - Brings up the RP Fortune Teller interface menu
	/rpf_tell - Tell a prophecy (run once to peer into the future, again to reveal it)
	/rpf_task - Give a task (run once to look for a task, again to hand it out)
	/rpf_bar - Show/hide the Prophecy/Task button bar
	/rpf_zone - Shows the exact zone name to use when adding zone tasks
	/rpf_lucky - Allows you to reveal lucky numbers
	
Interface Menu Options (the menu also lists all slash commands):
	- Force Targeted Options - Checking this box will force the fortunes/gazes to pull from the "targeted" list when a target is highlighted. Unchecking this allows the addon to pull from all lists when a target is highlighted.
	- Show Prophecy/Task Button Bar - Shows or hides the on-screen button bar (same as /rpf_bar).
	- Lucky Numbers to Return - This slider lets you determine how many lucky numbers can be chosen. 
	- Max Lucky Number Values - This slider allows you to choose the maximum value that can be used for a lucky number.
